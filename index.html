2. Estrutura, Estilo e Comportamento

Como cada tecnologia trabalha em conjunto nesta página.

HTML

HTML Semântico

Utiliza tags com significado claro como <header>, <main>, <section> e <footer>, facilitando a leitura por navegadores e tecnologias assistivas.

CSS

Layout com Flexbox

Organiza os elementos de forma flexível e responsiva em linhas ou colunas (flex-row, justify-between, items-center), adaptando-se a celulares e computadores.

JS

DOM & Lógica

Escuta eventos do usuário (addEventListener) e aplica estruturas condicionais (if / else) para atualizar textos, cores e estados em tempo real.

♿ Acessibilidade na Web

Desenvolver para a web significa incluir todas as pessoas. Nesta página, aplicamos contraste adequado entre texto e fundo, indicadores de foco visíveis ao navegar com a tecla Tab e atributos ARIA (aria-live, aria-label) para leitores de tela.

🤝 Ética nas Interações Digitais

A interatividade com JavaScript deve respeitar a autonomia e o bem-estar do usuário. Isso envolve evitar padrões manipulativos (dark patterns), garantir transparência nas ações dos botões e criar interfaces honestas, seguras e acolhedoras.
